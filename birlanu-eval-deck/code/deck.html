01What was tested

One dataset per mapping logic, each built to exercise that logic.

Each logic was run on its own set of 100 product titles, so the four results read lane by lane.
SKU-based
Titles that carry an embedded product code — the code path on its own.

Brand-based
Titles carrying the brand token and no code — the brand path on its own.
“1 1/2" UPVC TEE BIRLA” · “1 1/4" cpvc Socket Birla”
Plain title
No code and no brand token — matching on the words alone.
“110MM 45 ELBOW” · “CPVC SOCKET 1"”

03How it was scored

Two questions per title: was the status right, and was the SKU right.

01
Status
Mapped, mapped-but-brand-not-found, or unmapped — compared with the result recorded for that title before the run.
02
SKU
The product chosen against the expected product; equivalent catalogue items count as correct. Confidence is recorded but never counted.
03
Errors
A wrong map is a title mapped where the record says unmapped; a miss is a title left unmapped where the record wants a mapping.
Status accuracy = (titles − wrong maps − misses) ÷ titles · SKU accuracy = (titles − wrong maps − misses − wrong SKU) ÷ titles. Every title is scored the same way; each set was run once against the live production catalogue, under the same conditions.
